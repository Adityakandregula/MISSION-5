# Contributing to Kanban Task Board

Thank you for your interest in contributing! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/kanban-task-board.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Install dependencies: `npm install`

## Development

- Run development server: `npm run dev`
- Run linter: `npm run lint`
- Build for production: `npm run build`
- Preview build: `npm run preview`

## Code Standards

- Use React hooks for state management
- Keep components functional and reusable
- Follow ESLint configuration
- Write descriptive variable and function names
- Add comments for complex logic

## Commit Guidelines

- Use clear, descriptive commit messages
- Reference issues when applicable (e.g., "Fixes #123")
- Keep commits focused on single features or fixes

## Pull Requests

1. Ensure all tests pass and code is linted
2. Provide a clear description of changes
3. Link related issues
4. Request review from maintainers

## Feature Ideas

- Drag-and-drop task reordering
- Task categories/tags
- Due dates and reminders
- Collaborative editing
- Export/import functionality
- Dark mode

## Questions?

Feel free to open an issue for questions or discussions.
